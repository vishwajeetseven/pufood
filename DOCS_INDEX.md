## Quick Start

### For Users

**Web:**
Visit [https://pufood.xyz](https://pufood.xyz)

**Mobile:**
Download from Google Play Store or [direct APK](https://pufood.xyz/downloads/)

### For Developers

**Web Development:**
```bash
git clone https://github.com/iad1tya/pufood.git
cd pufood
python -m http.server 8000
# Open http://localhost:8000
```

**Mobile Development:**
```bash
git clone https://github.com/iad1tya/pufood.git
cd pufood/app
flutter pub get
flutter run
```

## Documentation Standards

Our documentation follows these principles:

1. Clear and Concise - Easy to understand
2. Up-to-date - Reflects current codebase
3. Example-rich - Includes code samples
4. Accessible - For all skill levels
5. Comprehensive - Covers all aspects

## Contributing to Documentation

Documentation improvements are highly valued.

How to contribute:

1. Fork the repository
2. Edit the relevant .md file
3. Submit a pull request
4. Follow the [CONTRIBUTING.md](CONTRIBUTING.md) guidelines

Good documentation PRs include:
- Clear writing
- Code examples
- Screenshots (for UI features)
- Updated table of contents
- Spell-checked content
